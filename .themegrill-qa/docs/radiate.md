## Installation

Installing your theme is pretty easy! After downloading you should have a radiate.zip file. This is a compressed file containing all of the required templates and images required for the theme to function properly.

### Upload Theme

- Go to Appearance > Themes in the WordPress Dashboard

- Click on the Add New button

- Click on the Upload link

- Select the radiate.zip file

- Click on Install Now button

### Activate the theme

Go to Appearance > Themes in the WordPress Dashboard.

Now, hover over the theme thumbnail and press the Activate button

Additional information: WordPress Codex – Using Themes

## Custom Menu

By default, the menus will fallback to Pages. That means just after activation of the theme, you will see all the pages as menus. If you want selective menus with combination of links, pages, categories then custom menu is what you should be looking for.

Just like custom menus give you more control and a tailored experience, the same applies to how people choose to relax and have fun online. Platforms like pinup offer users the flexibility to explore games that suit their personal taste – from classic slots to live tables, creating an experience as unique as your website’s navigation.

### Set up Custom Menu

- Go to Appearance > Menus in the WordPress menu

- Click on Create a new menu link

- Give a name to your menu in Menu Name and click Create Menu button

- Now choose the pages, categories, custom links from the leftside of your screen by selecting the checkbox and click on Add Menu

- Click Save Menu after adding required pages, categories in the menu

## Home Page Slider

This theme supports the home page image slider. To use it follow the steps below.

#### Steps

- Go to Appearance > Customize in the WordPress menu

- Now go to the Slider section.

- To activate the slider, check the Check to activate slider checkbox

- Upload the image # 1 for the first slider. Similarly, add the corresponding slider title, slider description and redirect link. You can link to a link within your site or outside of your site.

- Repeat the above step for your other slides.

- Now, click on Save & Publish button. That’s it, open your home page and it should be there. 🙂

## Header Settings

All the options related to Header part are available in Appearance-> Customize-> Header Media.

### Header Image

- Go to Appearance > Customize > Header Media > Header Image in the WordPress menu

- Now, Upload the header image from the Add new image button there.

Recomanded size of header image is 1500 X 450 Pixels.

- Now after selecting the header image, it will ask you to crop. If you like to crop it, then, you can crop else leave it as you want for your site to best suit it.

- Now, click on Save & Publish button.

## Front Page Featured Section

To set the your front page featured section to display your featuerd page in home page.

#### Steps

- Go to Appearance > Customize > Front Page Featured Section in the WordPress menu.

- Now select the page from dropdown options to dispay it.

- Now, click on Save & Publish button.

## Design Options

Design based settings is available in Appearance-> Customize

### Custom CSS Box

Custom CSS Box is available in Appearance-> Customize-> Custom CSS

Radiate have Custom CSS Box which will ease your work if you need to add CSS in your site. Note: It will strip all the tags. Also, we strongly recommend not to edit the code in the theme’s file. All you changes will be lost if you update the theme. Use child theme instead.

### Header Search Icon

Header Search Icon Is available in Appearance-> Customize-> Header Search Icon

Radiate have Header Search Icon option which will allow you to enable/disable the search icon in your header section.

### Layout Settings Section Pro

Layout Settings Section is available in Appearance-> Customize-> Layout Settings Section

Select default layout. This layout will be reflected in whole site archives, search, single page, single post etc.

- Right Sidebar

- Left Sidebar

- No Sidebar Content Full Width

- No Sidebar Content Center

If you don’t want any sidebar than select “No Sidebar Full Width” or “No Sidebar Content Centered”

### Featured Image Display Options Pro

Featured Image Display OptionsIs available in Appearance-> Customize-> Featured Image Display Options

Radiate have Featured Image Dispaly options which will allow you to enable/disable the featured thumbnail image to display in single post or sngle page.

Now if you want to reduce or increase the number of words that appear in services widgets or post. You can easily change that.

#### Steps

- First Go to the service widget page or post in your dashboard.

- Just below the page editor you will see the excerpt box

- If you don’t see the excerpt box. Scroll to the top and you will see the screen options on the right hand side corner.

- Click it and check the Excerpt box. Now you should see the excerpt box below the editor.

- Fill the excerpt box with the desired amount of text that you want to show.

## Recommended Image Size

Since this theme heavily relies on the featured images of the post to be displayed the content of your site uniquely as it is best suited for the news/magazine site. So, we have created different recommended image size for this theme. Recommended image size (width*height) used in Spacious theme in px.

- Recommended image size for Slider – 1400*600

- Recommended image size for normal layout post featured image – 768*350

- Recommended image size for block layout post featured image – 830*370
